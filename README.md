# 钥匙 / 工具 / 标识牌 借用登记与归还确认系统

本系统部署在本机（Windows），后台服务监听 **端口 10800**，借用人通过手机微信扫描后台生成的二维码即可在线登记借用信息。

---

## 一、启动方法

### 方式一：双击启动（推荐）
双击项目目录下的 **`start.bat`** 即可启动服务。

### 方式二：命令行启动
```bash
cd "D:\DSH\Key Borrow-Register System"
npm start
```

> **Windows 上推荐用脚本后台静默运行（无黑窗口）**：双击 `start.bat` 后台启动并自动打开浏览器（脚本会自动检测 Node.js 是否安装、端口 10800 是否空闲，失败会给出中文提示并可在 `server-err.log` 查看原因）；停止服务双击 `停止服务.bat`；启动异常先双击 `环境自检.bat` 一键排查。命令行方式 `npm start` 用于调试。

启动成功后，控制台会显示：

```
本机访问:   http://localhost:10800
局域网访问: http://192.168.x.x:10800   （手机微信扫码用）
```

> 首次使用若提示缺少依赖，先在项目目录执行 `npm install` 一次。

## 二、访问地址与账号

| 页面 | 地址 | 用途 |
|---|---|---|
| 工作台（管理员/运行人员） | `http://localhost:10800` | 登录后管理借用记录 |
| 借用登记页（借用人） | `http://localhost:10800/borrow` | 手机微信扫码进入登记 |

**默认账号**（首次登录后请及时修改）：

| 角色 | 用户名 | 密码 | 权限 |
|---|---|---|---|
| 管理员 | `admin` | `admin123` | 全部权限：查看/修改/确认/归档/删除/导出/用户管理/二维码 |
| 运行人员 | `operator1` | `123456` | 修改、确认借用人提交的信息，留下确认标志；归还确认；查看与提醒 |
| 运行人员 | `operator2` | `123456` | 同上 |

> 借用人**无需登录**，直接扫码登记即可。

## 三、使用流程

0. **（推荐）导入物品库存**：管理员/运行人员登录工作台 → 「📦 物品管理」→「⬇ 下载导入模板」→ 用 Excel/WPS 填写（物品类型/名称/数量）→ 另存为 **CSV UTF-8** →「📥 导入库存 CSV」。导入后，借用人登记时名称框会**自动联想**库存物品，**被借完的物品不可选**；库存不足提交会被拦截。
1. **管理员/运行人员登录工作台** → 进入「借用二维码」页 → 将二维码打印或展示在值班处。
2. **借用人**用手机微信扫码 → 打开「借用登记」页 → 填写姓名、**手写签字**、借用物品（可点「＋ 添加物品」一次登记多件物品，每件含类型/名称/数量）、借用时间（默认当前时间，可改）、计划归还时间（自动为借用时间 +8 小时，可改）→ 提交。
3. **运行人员**在「借用目录 → 待确认」中查看申请，可**修改**信息，确认无误后点 **「✔ 确认借用」**，记录留下 **确认标志**（确认人 + 确认时间），物品放行。
4. **归还**时在「借用中」列表点 **「↩ 归还确认」** → 记录**自动归档**，不再显示在借用目录。
5. **超期提醒**：到达计划归还时间仍未归还，系统会以**红色高亮**标注，并在工作台顶部弹出 **🚨 超期提醒横幅**，同时向管理员与运行人员发出浏览器通知。

## 四、手机扫码访问（重要）

手机要能访问本机服务，需满足：

1. **同一局域网**：手机与本机连接同一 WiFi / 网段。
2. **防火墙放行端口 10800**：在 **管理员 PowerShell** 中执行一次以下命令：
   ```powershell
   netsh advfirewall firewall add rule name="借用登记系统10800" dir=in action=allow protocol=TCP localport=10800
   ```
   （如需取消放行：`netsh advfirewall firewall delete rule name="借用登记系统10800"`）
3. 用手机浏览器测试访问：`http://<本机局域网IP>:10800/borrow`，能打开即表示手机可访问。

> 二维码默认使用自动检测到的本机局域网 IP 生成；若使用了路由器端口映射 / 内网穿透 / DDNS，可在二维码页的「访问地址」框中填写对外地址后重新生成。

## 五、数据与导出

- 数据保存在项目目录 **`data/`** 文件夹（`users.json` 账号、`borrows.json` 借用记录），**重启/关机不丢失**。备份时直接复制该文件夹即可。
- 工作台「数据导出」页可导出 **全部 / 借用中 / 归档** 三类 CSV 文件（UTF-8 带 BOM），Excel / WPS 直接打开正常显示中文。
- 导出字段：借用单号、借用人、物品类型、物品名称、数量、借用时间、计划归还时间、实际归还时间、状态、确认人、确认时间、归还人、是否超期、备注、创建时间。

## 六、常见问题

- **双击 start.bat 提示“服务已经在运行中”**：说明端口 10800 已被占用（服务已启动）。此时无需重复启动，脚本会自动打开 http://localhost:10800。若确需重启服务，先在任务管理器结束 node 进程，再运行 start.bat。
- **手机打不开页面**：① 确认同一局域网；② 执行上面的防火墙放行命令；③ 用 `ipconfig` 确认本机 IP 与二维码地址一致。
- **微信扫码提示“非微信官方网页”**：属正常提示（内网 HTTP），点「继续访问」即可打开。
- **忘记管理员密码**：删除 `data/users.json` 后重启服务，会自动恢复默认账号（admin/admin123）。
- **修改端口**：编辑 `server.js` 顶部 `const PORT = ...` 或运行前设置环境变量 `PORT`。
- **浏览器不弹超期通知**：请在浏览器地址栏允许本页面的通知权限。
