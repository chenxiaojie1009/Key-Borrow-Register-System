导入说明：① 点击「下载导入模板」，用 Excel / WPS 打开，按模板填写物品类型（钥匙/工具/标识牌或其他）、物品名称、数量（库存总数）；

③ 点击「导入库存 CSV」选择文件，同名同类型的物品将覆盖数量，新名称自动新增；
④ 借用人登记时，被借出后未归还的物品会从可用候选中消失，可用数量不足时无法借用。

借用登记二维码
借用人使用手机微信扫码，即可打开借用登记页面
使用说明：
① 将本页面展示的二维码打印 / 保存，贴在值班台或借用处；
② 借用人使用手机微信扫码（或手机浏览器扫码）→ 打开「借用登记」页面 → 填写信息并手写签字 → 提交；
③ 提交后，运行人员在「借用目录 → 待确认」中审核、可修改信息并点「确认借用」；
④ 归还时在「借用中」列表点「归还确认」，记录自动归档。

手机访问前提：手机需与本机在同一局域网（同一 WiFi/网段），且本机防火墙已放行端口 10800（见 README 中的放行命令）。
数据导出（CSV，可用 Excel 打开）
导出文件为 CSV 格式（UTF-8 带 BOM），使用 Excel / WPS 直接打开即可正常显示中文。 导出的字段包含：借用单号、借用人、物品类型、物品名称、数量、借用时间、计划归还时间、实际归还时间、状态、确认人、确认时间、归还人、是否超期、备注、创建时间。
